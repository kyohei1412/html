# HTML / JavaScript 作品集（3作品）

## 概要
HTML・JavaScriptの基礎学習として、ブラウザ上で動作するミニアプリを3つ作成しました。  
入力処理・Canvas描画・アニメーション処理などを実装し、Web制作の基礎を身につけることを目的に制作しました。

## 作品一覧
### 1. 電卓（calculator.html）
**入力した数式を計算して結果を表示するシンプルな電卓**です。

**主な機能**
- 数式入力（例：`1+2*3`）
- 「＝」ボタンで計算結果を表示
- 不正な文字を入力できないように制限（数字と + - * / . のみ）

---

### 2. Canvasアニメーション（canvas1.html）
**ボールが画面内を跳ね返りながら動くアニメーション**です。  
壁に当たると色が変化し、一定回数当たるとボールが増殖します。

**主な機能**
- ボールの移動と壁反射
- 衝突時に色を変更
- 衝突回数に応じてボールを増殖（最大50個まで）

---

### 3. 時計（clock.html）
**アナログ時計とデジタル時計を同時に表示するCanvas時計**です。  
日付と曜日も表示します。

**主な機能**
- 短針・長針・秒針の描画
- 目盛り（60目盛り）と数字（1〜12）の表示
- デジタル時刻（HH:MM:SS）表示
- 日付・曜日表示
- 1秒ごとに自動更新

---

## 使用技術
- HTML
- JavaScript
- HTML5 Canvas

## 実行方法
1. このリポジトリをダウンロード、またはクローンします
2. 以下のファイルをブラウザで開くと動作します

- `calculator.html`
- `canvas1.html`
- `clock.html`
